# bref

The Flutter editor of [Bref](https://github.com/citadellefr/bref): Markdown
notes edited together in real time, against the Go server.

```dart
import 'package:bref/bref.dart';

BrefEditor(session: session, theme: BrefTheme.of(context));
```

The session is [trame's](https://github.com/citadellefr/trame) `DocSession`.
See the [repository README](https://github.com/citadellefr/bref#readme).
